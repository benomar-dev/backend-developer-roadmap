## 📅 Weekly Study Schedule Suggestion

```
Monday    → Theory + reading (1h) + coding exercises (1h)
Tuesday   → Continue exercises or project work (2h)
Wednesday → New topic or tutorial (2h)
Thursday  → Project work (2h)
Friday    → Code review / refactoring / tests (1.5h)
Saturday  → Longer session: project or course (3h)
Sunday    → Review week's learning, plan next week (1h)
```

**Key principle: 70% practice, 30% theory. Always have a project running.**
