# Java Core Topics

This README provides an overview of Java Core topics with exercises and practice problems. It is designed for beginners and those looking to refresh their skills.

## Topics Covered
1. **Basic Syntax**  
   Understand the fundamentals of Java syntax including variables, data types, and operators.

2. **Control Flow Statements**  
   Learn about decision-making using `if`, `else`, and switch statements.

3. **Loops**  
   Masters `for`, `while`, and `do-while` loops.

4. **Methods**  
   Explore method declaration, definition, and overloading.

5. **Object-Oriented Programming**  
   Delve into classes, objects, inheritance, polymorphism, encapsulation, and abstraction.

6. **Exception Handling**  
   Understand try, catch, throw, and finally blocks.

7. **Collection Framework**  
   Familiarize yourself with Lists, Sets, Maps, and their implementations.

8. **File I/O Operations**  
   Learn how to read and write files in Java.

## Exercises and Practice Problems
- **Basic Syntax:**  
  Write a program that prints "Hello, World!".

- **Control Flow:**  
  Create a program that determines whether a number is odd or even.

- **Loops:**  
  Write a program that prints the Fibonacci sequence up to a certain number.

- **Methods:**  
  Implement a method that calculates the factorial of a number.

- **OOP:**  
  Design a simple class that represents a `Car` with attributes and methods.

- **Exception Handling:**  
  Create a program that handles exceptions when dividing by zero.

- **Collections:**  
  Write a program to manage a list of student names using ArrayList.

- **File I/O:**  
  Create a program that reads from a file and displays its content.

## Conclusion
Mastering Java Core is essential for any developer looking to advance in their career. Practice these topics regularly to solidify your understanding and skills.
