## 🏆 What Employers Look For

Each project must demonstrate:
- ✅ Clean, readable code following SOLID and DRY principles
- ✅ RESTful (or GraphQL) API with proper status codes and error handling
- ✅ Authentication & authorisation (JWT / OAuth2)
- ✅ Unit and integration tests (>70% coverage)
- ✅ API documentation (Swagger/OpenAPI)
- ✅ Dockerised application
- ✅ CI/CD pipeline (at least GitHub Actions)
- ✅ Professional README with setup instructions

## 📋 Project README Template

Each project folder should contain a README with:

```markdown
# Project Name

## Description
One paragraph describing what the project does and why.

## Tech Stack
- Java 17 / Spring Boot 3.x
- PostgreSQL 15
- Redis 7
- Docker / Docker Compose

## Architecture
(diagram or description)

## Getting Started
### Prerequisites
- Java 17+
- Docker & Docker Compose

### Run locally
git clone ...
cd project
docker-compose up -d
./mvnw spring-boot:run

## API Documentation
Swagger UI: http://localhost:8080/swagger-ui.html

## Running Tests
./mvnw test

## CI/CD
Describe your pipeline (GitHub Actions / GitLab CI)

## Deployment
How to deploy to GCP / Cloud Run
```
