## 💼 Compétences Requises pour Junior Spring Boot Developer

### Compétences Essentielles (Must-Have)

✅ **Java Core**
- Java 11+ (idéalement Java 17 ou 21)
- POO (Programmation Orientée Objet)
- Collections Framework
- Streams API & Lambda expressions
- Exception Handling

✅ **Spring Framework**
- Spring Boot 2.x ou 3.x
- Dependency Injection (DI)
- Spring MVC
- Spring Data JPA
- Spring Security (basics)

✅ **APIs RESTful**
- Conception API REST
- HTTP Methods (GET, POST, PUT, DELETE)
- Status Codes
- JSON/XML
- Postman/Insomnia

✅ **Bases de Données**
- SQL (PostgreSQL ou MySQL)
- JPA/Hibernate
- Requêtes CRUD
- Relations (OneToMany, ManyToMany)

✅ **Outils**
- Git & GitHub/GitLab
- Maven ou Gradle
- IntelliJ IDEA ou Eclipse
- Docker (basics)

### Compétences Appréciées (Nice-to-Have)

⭐ **Testing**
- JUnit 5
- Mockito
- Tests d'intégration

⭐ **DevOps**
- CI/CD (GitLab CI, GitHub Actions)
- Docker Compose
- Cloud (AWS, GCP, Azure)

⭐ **Architecture**
- Microservices (concepts)
- Design Patterns
- Clean Code

⭐ **Frontend (bonus)**
- Angular, React, ou Vue.js (basics)
- HTML/CSS

## 🎯 Préparation aux Entretiens

### Phase 1: Entretien RH (30-45 min)

**Questions typiques:**
- Présentez-vous
- Pourquoi ce poste?
- Pourquoi l'Espagne?
- Prétentions salariales
- Disponibilité

**En espagnol, préparez:**
- "Cuéntame sobre ti" (Parlez-moi de vous)
- "¿Por qué quieres trabajar en España?" (Pourquoi l'Espagne?)
- "¿Cuáles son tus expectativas salariales?" (Prétentions salariales)

### Phase 2: Entretien Technique (60-90 min)

**Topics à réviser:**

1. **Java Core**
   - Différence entre `==` et `.equals()`
   - Interface vs Classe abstraite
   - Collections (List, Set, Map)
   - Streams et Lambda
   - Exception handling

2. **Spring Boot**
   - Qu'est-ce que Spring Boot?
   - Dependency Injection
   - Annotations (@Component, @Service, @Repository, @RestController)
   - Spring Bean lifecycle
   - Application.properties vs application.yml

3. **API REST**
   - Qu'est-ce que REST?
   - HTTP Methods et quand les utiliser
   - Status Codes (200, 201, 400, 404, 500)
   - Différence entre @PathVariable et @RequestParam
   - Comment gérer les erreurs dans une API

4. **Base de Données**
   - Différence entre JPA et Hibernate
   - Qu'est-ce qu'une transaction?
   - ACID properties
   - Lazy vs Eager loading
   - N+1 problem

5. **Testing**
   - Types de tests (Unitaires, Intégration)
   - JUnit basics
   - Pourquoi tester?

### Phase 3: Live Coding (45-60 min)

**Exercices typiques:**

1. **CRUD API**
   - Créer une API REST simple (ex: gestion de livres)
   - Endpoints: GET, POST, PUT, DELETE
   - Validation des données

2. **Algorithmes**
   - Manipulation de Collections
   - Streams API
   - Problèmes simples (FizzBuzz, Palindrome, etc.)

3. **Debugging**
   - Trouver et corriger un bug dans du code Spring Boot

**Plateformes pour s'entraîner:**
- LeetCode (Easy level)
- HackerRank (Java)
- Exercism (Java Track)

## 💡 Conseils Spécifiques pour l'Espagne

### 1. Visa et Permis de Travail

**Pour citoyens UE:**
- Pas de visa nécessaire
- NIE (Número de Identidad de Extranjero) à obtenir en arrivant

**Pour citoyens hors UE:**
- Visa de travail nécessaire
- L'entreprise doit sponsoriser
- Certaines entreprises ne sponsorisent pas les juniors

### 2. Adaptation Culturelle

**Horaires de travail:**
- Souvent 9h-18h ou 9h-19h
- Pause déjeuner: 14h-15h (parfois longue)
- Flexibility selon l'entreprise

**Style de communication:**
- Plus informel qu'en France
- Tuteo (tutoiement) fréquent
- Ambiance généralement décontractée

### 3. Salaire et Négociation

**Fourchette Junior (2023-2024):**
- Madrid: 25,000-35,000€ brut/an
- Barcelona: 24,000-33,000€ brut/an
- Autres villes: 22,000-30,000€ brut/an

**Éléments de négociation:**
- Formation continue
- Remote/Hybrid
- Ticket restaurant
- Assurance santé privée
- Budget formation/certifications

### 4. Portfolio GitHub

**Indispensable:**
- Minimum 3-4 projets Spring Boot
- Code propre et documenté
- README.md professionnels
- Commits réguliers (green squares)

**Projets suggérés:**
1. API REST CRUD simple (Blog, Todo List)
2. Application avec authentification JWT
3. Microservice avec Spring Cloud
4. Application avec Docker

### 5. Certifications Valorisées

1. **Oracle Certified Java Programmer** (OCJP)
2. **Spring Professional Certification**
3. **AWS Certified Cloud Practitioner** (si cloud)

### 6. Apprentissage de l'Espagnol

**Ressources:**
- Duolingo (basics)
- italki (cours particuliers)
- Tandem (échange linguistique)
- Netflix en espagnol avec sous-titres

**Niveau minimum recommandé:** B2
